# Lumi Update v0.8 — Appearance Studio

Cumulative update over v0.7. Uses the same Android application ID and signing key so it is designed to install as an update over earlier Lumi builds.

## Added in v0.8
- Appearance Studio
- Persistent wardrobe state
- Change/update/remove individual clothing layers
- Tops, bottoms, outer layers, shoes, accessories and hairstyles
- Context/style mood presets
- Lumi-controlled random outfit experimentation
- Natural-language appearance commands
- Reset to Lumi default appearance

## Notes
This is still the phone prototype. The current avatar is a UI representation; a future animated/rendered avatar engine will consume these saved appearance states visually.
